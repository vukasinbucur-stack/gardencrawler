# Security Policy

## Supported Versions

Currently in development. No stable releases yet.

## Reporting a Vulnerability

If you find a security vulnerability in Garden-Crawler:

1. Please do **NOT** create a public issue
2. Email your findings to: vukasin.bucur@gmail.com
3. Include details about the vulnerability
4. Allow time to fix before disclosing

## What Qualifies as a Security Issue?

- Remote code execution
- Unauthorized access to the robot
- Physical safety vulnerabilities
- Data privacy issues

## What Doesn't Qualify

- General bugs (use regular issues)
- Feature requests (use regular issues)
- Documentation errors (use regular issues or PR)

## Safety Notes

Garden-Crawler is a physical robot. Always:

- Keep the E-stop accessible when testing
- Disconnect power when working on hardware
- Test in a safe area away from people/animals
- Never leave the robot unattended while powered

This robot has moving parts that can cause injury. Use common sense.
