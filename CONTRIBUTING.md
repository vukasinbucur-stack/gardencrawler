# Contributing to Garden-Crawler

Thanks for your interest in contributing! Garden-Crawler is an open-source project and all contributions are welcome.

## Ways to Contribute

You don't need to be an expert to help. Here are some ways to contribute:

### Code & Firmware

- Improve motor control algorithms (PID, path planning)
- Optimize encoder reading
- Add sensor support
- Improve vision models for weed/crop detection

### Hardware

- Design better motor mounts
- Improve the rocker-bogie suspension
- Design a weeding tool mechanism
- Create 3D printable parts

### Documentation

- Fix typos
- Add missing information
- Translate documentation
- Add photos of your build

### Testing

- Build your own Garden-Crawler and report issues
- Suggest improvements based on real-world use
- Share your modifications

## Getting Started

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Make your changes
4. Commit your changes (`git commit -m 'Add amazing feature'`)
5. Push to the branch (`git push origin feature/amazing-feature`)
6. Open a Pull Request

## Code Style

- Python: Follow PEP 8
- Comment complex logic
- Add docstrings to functions
- Keep functions focused and small

## Hardware Design

- Use metric measurements
- Specify materials clearly
- Include STL files for 3D printed parts
- Note source of non-standard parts

## Pull Request Guidelines

- Describe what your PR does
- Link to related issues
- Add/update documentation as needed
- Test your changes if possible

## Questions?

Open an issue with the "question" label and I'll do my best to help!
